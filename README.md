# ARISE Website Demo

A lightweight demonstrator for a public ARISE research programme website.

## Goal

Show that ARISE can publish people, projects, publications, news, media coverage and research outputs using a static-site architecture with effectively zero hosting cost.

## Proposed stack

- Astro + TypeScript
- Astro content collections
- Static build only
- GitHub Actions for deployment
- GitHub Pages for hosting
- No database, CMS licence or application server

## Demo scope

The first demo should include:

- Home
- About
- Projects / Research
- One representative project (ISC-XR)
- People
- Publications
- News
- In the Media
- Partners / Contact

All sample content must be clearly marked and must not invent research claims.

## Deployment options

1. GitHub Pages URL — £0/year
2. Institutional subdomain pointing to GitHub Pages — £0/year to ARISE if provided by a partner institution
3. Standalone domain — domain registration only; hosting and deployment remain free

## Status

Scaffold only. Intended to be developed with Codex before the ARISE website discussion.
